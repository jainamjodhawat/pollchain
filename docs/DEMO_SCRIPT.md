# PollChain Level 5 Demo Script

Use this outline to record the final 5–7 minute walkthrough after the Level 5 deployment and real-user campaign are complete.

## 1. Problem and product — 45 seconds

Explain that small communities often discuss decisions in one tool, identify members in another and rely on screenshots for voting proof. Introduce PollChain as a Stellar governance flow where proposals, votes and transaction evidence remain publicly verifiable.

## 2. New-user onboarding — 60 seconds

Open the live app on the Start page. Show the connect → fund → act trail, connect Freighter on Stellar testnet and explain the visible progress states. Never expose a secret key or seed phrase.

## 3. Real governance action — 90 seconds

Open a live proposal, show both Yes and No controls, submit a vote and point out the immediate percentage response. Wait for confirmation, then show the activity receipt with wallet, transaction hash and StellarExpert link.

## 4. Personal and community views — 60 seconds

Show My Proposals, the improved leaderboard and one analytics or delegation view. Explain how the shared wallet session keeps connected state consistent across routes.

## 5. Architecture — 60 seconds

Use the architecture document or pitch-deck slide to show the React/Freighter integration and six Soroban contracts: voting, governance token, execution, treasury, faucet and delegation.

## 6. Real-user proof — 60 seconds

Open the completed workbook dashboard and show 50 unique wallets, evidence-ready rows and interval compliance. Open several StellarExpert transaction links. Do not display private names or emails.

## 7. Learning and roadmap — 45 seconds

Summarize the top feedback theme, show the linked improvement commit and explain the next product decision. End on the live application and public repository URLs.
